## তুলনার ফল

- ফোনে শিরোনাম, তিন ধাপের কার্ড, চার্টের তালিকা, মাপের টেবিল, ঘরের মাপ (৫৪ px), "কীভাবে মাপবেন" ছবি, সব সাইজ আছে কি না,
  সেভ আর কপি বোতাম আর "পণ্য যোগ করার সময়" ঘর ডেমোর মাপেই আছে। পাশে সরে যাওয়া (horizontal scroll) ০।
- ডেস্কটপে তালিকা ৩৪০ px, টেবিলের ঘর ৭৬ px, ডেমোর জায়গাতেই।
- যেটুকু আলাদা, তার কারণ:
  - চার্টের সংখ্যা আর নাম নমুনা ডেটার (৭টা); ডেমোতে ১৫টা। তালিকা নাম অনুযায়ী সাজানো, তাই ছবির আগে "Polo · Regular fit" বেছে নেওয়া হয়েছে।
  - উপরের বারে দোকানের নাম নেই, কারণ নমুনা ডেটায় দোকানের নাম (মালিকের তথ্য) দেওয়া নেই। মেনুতে এখন শুধু তৈরি হওয়া পাতাগুলো।
  - "স্পেক শিটের ছবি থেকে পড়ুন (AI)" বোতাম এখনো নেই — এটা AI-এর ধাপে আসবে। টাইপ বা পেস্ট করে একই কাজ হয়।
  - বাড়তি: "নতুন চার্ট", "যেসব ক্যাটাগরির ডিফল্ট" (ডিফল্ট দেওয়া/সরানো), পণ্যের নিজের চার্ট থাকলে "আবার অটো", আর "চার্ট আর্কাইভ
    করুন" (মোছে না) — রেজিস্টারে PR 28-এ এগুলো চাওয়া হয়েছে।
  - টেবিলের "ইঞ্চি" লেখাটা একটু গাঢ়, যাতে পড়তে সহজ হয় (Lighthouse-এর রঙের পরীক্ষা পাস)।
