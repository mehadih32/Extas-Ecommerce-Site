# PR 99 — কাস্টমার কী মিলিয়ে নিতে পারে (যেকোনো ২টা X, যেকোনো ৩টা Y): ছবি

ফোন 390×844, ডেস্কটপ 1366×900। ছবির দুইটা "নিজের মতো সেট" নিয়ম শুধু ছবির জন্য বানানো, দাম বানানো (আসল দাম নয়);
এগুলো রিপোতে নেই। মালিক নিজের নিয়ম আর দাম স্মার্ট নিয়ম পাতায় দেবেন।

## মাপের ফল

- পাশে সরে যাওয়া ০, ৪৪ px-এর ছোট বোতাম ০, কাঁচা লেখা-চাবি ০, কনসোলে ভুল ০।
- দাম আর চালু/বন্ধ এখানে বদলায় না — একটাই জায়গা, স্মার্ট নিয়ম; সেখানে দাম বদলাতে মালিকের অনুমতি লাগে। তাই ডেমোর
  দামের ঘরের বদলে দাম দেখানো হয়েছে আর "স্মার্ট নিয়ম খুলুন" বোতাম আছে। দুই জায়গায় দাম লেখা গেলে দুইটা দাম হয়ে যেত।
- "কাস্টমার হিসেবে দেখুন" লিংক নেই — "সেট বানান" পাতা পরের স্টোরফ্রন্ট PR-এ (PR 98, 100) আসবে।
