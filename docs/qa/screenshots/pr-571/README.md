## মাপের ফল

- সব ছবিতে পাশে সরে যাওয়া (horizontal scroll) ০। ৪৪ px-এর ছোট বোতাম বা ঘর ০। কাঁচা লেখা-চাবি (যেমন `combos.…`) ০।
- ফোনে ট্যাব, ধাপের সারি (শুধু চলতি ধাপের নাম দেখায়), কার্ড আর নিচের আটকানো বার ডেমোর ক্রমেই আছে; ডেস্কটপে কার্ড তিন কলামে।
- সংখ্যা বাংলায় বাংলা অঙ্কে।
- যেটুকু আলাদা, তার কারণ:
  - "পেজ দেখুন" বোতাম নেই, শুধু লিংক কপি — দোকানের কম্বো পেজ পরের PR-এ (S03 স্টোরফ্রন্ট, PR 572–573) আসবে।
  - "আরও ১টা নিন → ৩ পিস"-এর দাম মালিক নিজে লিখবেন; ডেমোর মতো আন্দাজে দাম বসানো হয়নি।
  - সেটের ছবি এখনো আঁকা রঙের প্যানেল; আসল সেটের ছবি PR 575-এ।
  - ব্রাউজারের কনসোলে একটাই ভুল: `/favicon.ico` পাওয়া যায়নি — এটা দোকানের আইকনের কাজ, এই PR-এর নয়।
