## মাপের ফল

- কনসোলে ভুল ০, ভাঙা রিকোয়েস্ট ০, চারটা মাপেই (ফোন/ডেস্কটপ × বাংলা/ইংরেজি)।
- একবার চাপলে একটাই অর্ডার: দুইবার চাপলেও, নেট কেটে আবার চাপলেও একই অর্ডার নম্বর।
- দেখানো টাকা আর অর্ডারের টাকা এক (SIM-F-003): মাঝখানে দাম বা চার্জ বদলালে অর্ডার হয় না, নতুন হিসাব দেখিয়ে আবার কনফার্ম চাইতে বলে।
- ডেমোর সাথে পার্থক্য (পরের PR-এ আসবে): ধন্যবাদ পাতায় "অর্ডার ট্র্যাক করুন" (PR 135), "এসএমএস পাঠানো হয়েছে" লাইন (এসএমএস চালু হলে), "আপনার অ্যাকাউন্ট" কার্ড (PR 130) এখনো নেই।
- নমুনা দোকানের নাম দুই শব্দের, তাই ফোনে ধন্যবাদ পাতার মাথায় নামটা দুই লাইনে ভাঙে; EXTAS নামে এক লাইনেই থাকে। মাথার নকশা স্টোরফ্রন্টের কাজ, সেখানে জানানো হয়েছে।
