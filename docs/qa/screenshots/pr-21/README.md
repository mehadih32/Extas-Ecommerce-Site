# PR 21, 26, 29, 35 — প্রোডাক্টের পাতা: ছবি

ফোন 390×844, ডেস্কটপ 1366×900। "demo" মানে অনুমোদিত ডেমো (V12), "app" মানে আসল সাইট। সব ছবি নমুনা ডেটা দিয়ে তোলা
(নমুনা দোকান, নমুনা প্রোডাক্ট), মালিকের কোনো আসল তথ্য নেই। মাপের তুলনা: `metrics.md`।

## তুলনার ফল

- ফোনে শিরোনাম, "নতুন প্রোডাক্ট" বোতাম, খোঁজার ঘর, ছবির ঘর (56 px), রঙের চিপ, সাইজের বোতাম (52 px) আর সেভ বার
  ডেমোর মাপেই আছে। পাশে সরে যাওয়া (horizontal scroll) সব পাতায় ০। ছোট বোতাম (24 px-এর কম) ০টি। কনসোলে ভুল ০।
- ডেস্কটপে ডানের কলাম 330 px, ডেমোর মতোই; ফর্ম বাঁয়ে।
- যেটুকু আলাদা, তার কারণ:
  - ডেমোতে দাম পুরো প্রোডাক্টের একটাই; আসল সাইটে দাম প্রতিটা SKU-র (রেজিস্টার PR 19: দাম SKU-তে থাকে),
    তাই "SKU, দাম আর স্টক" ঘরটা লম্বা। স্টক শুধু দেখায় (ERP থেকে আসে), লেখা যায় না।
  - বাংলা নাম, যত্ন (care), গুগল টাইটেল-বর্ণনা আর লিংকের ঘর বাড়তি — রেজিস্টারের PR 590 আর PR 31 চায়।
  - "কম্বো" কার্ড নেই — ওটা PR 571-এর কাজ, পরে আসবে।
  - "দোকানে দেখুন" (চোখ) বোতাম নেই, কারণ দোকানের পাতা এখনো তৈরি হয়নি (S02); মরা লিংক রাখা হয়নি।
  - সংখ্যা ডেমোর মতো ইংরেজি অঙ্কে (1, 2, 3) লেখা।
  - পরীক্ষার সার্ভারে ছবির ফাইল রাখার জায়গা (Azure) এখনো যুক্ত নয় (নমুনা মোড), তাই আপলোড করা ছবিটা রঙের বাক্স
    হিসেবে দেখায়; আপলোড, প্রোডাক্টে বসানো আর গণনা ঠিকঠাক কাজ করছে।
