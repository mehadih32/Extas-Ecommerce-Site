## কী আছে, কী পরে আসবে

- ঠিকানা `/collections/<ক্যাটাগরি>` আর `/bn/collections/<ক্যাটাগরি>`; "নতুন এসেছে" হলো `/collections/new-in`। ফিল্টার আর সাজানো ঠিকানায় থাকে, তাই লিংক শেয়ার করলে একই পাতা খোলে; ফিল্টার করা পাতা গুগলে যায় না, মূল পাতা যায়।
- স্টক শেষ স্টাইল দেখায়, শেষে যায় বা লুকায় — সেটিং `category.page`।
- ক্যাটাগরির নিজের লেখা (গুগলের জন্য) আর নিজের প্রশ্ন মালিক দেবেন (`category.seo`, `category.faqOwn`); খালি থাকলে পাতায় দেখায় না। সাধারণ প্রশ্ন (ক্যাশ অন ডেলিভারি, ফ্রি ডেলিভারি, এক্সচেঞ্জ) তখনই দেখায় যখন সেই নিয়ম চালু।
- পরে আসবে: সেট-দামের ব্যানার আর "সেটের দাম আছে" ফিল্টার (S03), অফারের ব্যানার, ডেস্কটপে খালি ঘরে "Complete the look", "আমার সাইজ" চিপ (PR 58)।
