# PR 209 — স্মার্ট নিয়ম আর নোটিশ পাতা: ছবি

ফোন 390×844, ডেস্কটপ 1366×900। "demo" মানে অনুমোদিত ডেমো (V12.1), বাকিগুলো আসল সাইট। সব ছবি বানানো দোকানের নমুনা
ডেটা দিয়ে তোলা — আসল দাম, চার্জ বা এলাকা নেই। টাকার নিয়মগুলো খসড়া বা বন্ধ অবস্থায় আছে; মালিক ব্যাকএন্ড থেকে চালু করবেন।

## মাপের ফল

- সব ছবিতে পাশে সরে যাওয়া (horizontal scroll) ০। ছোট বোতাম (২৪ px-এর কম) ০। কাঁচা লেখা-চাবি (যেমন `rules.…`) ০।
- ফোনে উপরের বার, ট্যাব, শিরোনাম, "নতুন নিয়ম" বোতাম, গরমিলের ঘর, বিষয়ের চিপ আর কার্ড ডেমোর ক্রমেই আছে।
- ডেস্কটপে বাঁয়ে তালিকা, ডানে খোলা নিয়ম — ডেমোর মতোই।
- যেটুকু আলাদা, তার কারণ:
  - নমুনা নিয়মের সংখ্যা আর নাম ডেমোর থেকে আলাদা, কারণ এগুলো বানানো দোকানের নমুনা।
  - গরমিলের ঘরে নোটিশের নাম দেখায়, যাতে বোঝা যায় কোনটা ঠিক করতে হবে।
  - ব্রাউজারের কনসোলে একটাই ভুল আছে: `/favicon.ico` পাওয়া যায়নি। এটা দোকানের আইকনের কাজ, এই PR-এর নয়।
