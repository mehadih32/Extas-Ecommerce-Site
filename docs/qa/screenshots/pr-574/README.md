# PR 574 — ব্যাগে সেট, ৫ রকম সাজ (B1–B5): ছবি

ফোন 390×844, ডেস্কটপ 1366×900। ব্যাগে ৩টা নমুনা সেট (পরীক্ষার সার্ভারের `POST /api/bag/try?sets=3`), আসল দাম নেই।
B1–B5 দেখানো হয়েছে `?btpl=` দিয়ে; দোকানে এখনো "এখনকার চেহারা" (`combos.template.bag` = current), যতক্ষণ না মালিক বদলান।
সব সাজে মোট একই: ৳ 9,240।

| ছবি | কী দেখাচ্ছে |
|---|---|
| `current-en-*.png` | এখনকার চেহারা (PR 108-এর সেটের লাইন) — দোকানে এটাই থাকে |
| `b1-en-*.png` | B1 এক কার্ডে সেট, প্রতিটা পিসের নিজের ছবি |
| `b2-en-*.png` / `b2-bn-*.png` | B2 ব্যাগেই প্রতিটা পিসের সাইজ বদলানো; যে সাইজ স্টকে নেই সেটা "শেষ" |
| `b3-en-*.png` / `b3-bn-*.png` | B3 B2 + "আরেকটা নিন → 3টা ৳…" (রুলে 3 পিসের সেট থাকলে) |
| `b4-en-*.png` / `b4-bn-*.png` | B4 প্রতিটা পিসের নিজের দাম, এক লাইনে "কম্বো ছাড়", "এই কম্বোর জন্য দেবেন" |
| `b5-en-*.png` / `b5-bn-*.png` | B5 ৩টা বা বেশি সেট হলে প্রতিটা এক ছোট লাইনে; ▸ চাপলে B2 কার্ড খোলে। লেখা জায়গা না পেলে ছোট হয়, কাটা যায় না |

## মাপের ফল
- সব ছবিতে পাশে সরে যাওয়া ০, কনসোলে ভুল ০।
- আসল ব্রাউজারে চালিয়ে দেখা: B2-তে সাইজ বদলালে সাথে সাথে বদলায় (মোট একই থাকে), B3-তে "আরেকটা নিন" দিলে 3 পিসের সেট জোড়ার জায়গা নেয়।
