## তুলনার ফল

- ফোনে কাঠামোর ১২৩টা অংশ ডেমোর সাথে মাপা হয়েছে (মাপ, ফাঁক, অক্ষর, রং): ফারাক শুধু নমুনা ডেটার কারণে (নমুনা দোকানে সোশ্যাল লিংক আর ট্রেড লাইসেন্স আছে, ডেমোতে নেই)। ডেস্কটপে ১২৩টায় ০ ফারাক (চেকআউটে ২৬টায় ০)।
- ~~ফোন গেট: ১৩টা মাপে (ফোন, ট্যাবলেট, ডেস্কটপ) ১২৪ বার পাতা খোলা — পাশে সরে যাওয়া ০, ছোট বোতাম (৩২ px-এর কম) ০, ছোট লেখার ঘর ০।~~
- ডিভাইস গেট (PR 85, সব মাপের ফোন আর ট্যাবলেট): দোকানের ৬টা পাতায় ১৮৬ বার পরীক্ষা — ০ ভুল। প্রতিটা বোতাম আঙুলে চাপার জন্য অন্তত ৪৪×৪৪ px, অথচ চোখে দেখতে ডেমোর মতোই; পাশে সরে যাওয়া ০; লেখার ঘর ১৬ px।
- চলমান সারি: আঙুল ছোঁয়ালে থামে, ৪ সেকেন্ড পরে নিজে চলে; মাউস রাখলে থামে, সরালে চলে; কিবোর্ডে থামে, বের হলে চলে; "কম নড়াচড়া" চালু থাকলে নড়ে না।
- নতুন প্রতিটা চেহারা পেছনের সেটিং-এ বদলানো যায়, আগেরটাও রাখা আছে: মেনুর সাজ (৪ রকম), মেনুর ধরন (ছোট তালিকা / চওড়া প্যানেল), লোগোর ধরন (০–১০), ডেস্কটপ ফুটার (নমুনার মতো / আগেরটা)।
