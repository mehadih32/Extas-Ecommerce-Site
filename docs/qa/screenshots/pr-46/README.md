## কীভাবে কাজ করে

- প্রতিটা অপশন ক্যাটাগরির নিজের পণ্য থেকে আসে (মালিক, ১৯ অক্টোবর): যে সাইজ নেই সেটা দেখায় না, যে ফিট নেই সেটা দেখায় না।
- সংখ্যাগুলো অন্য ফিল্টার মিলিয়ে গোনা: "স্লিম ফিট" চালু থাকলে রঙের পাশে শুধু স্লিম পণ্যের সংখ্যা।
- সাইজ গোনা হয় শুধু যেখানে সেই সাইজ এখন কেনা যায়; কোথাও না থাকলে সাইজটা কাটা দাগে দেখায়, লুকায় না (SIM-F-035)।
- দামের ভাগ ক্যাটাগরির দাম দেখে নিজে হয় (৳৫০/১০০/২৫০/৫০০ ধাপে গোল); মালিক চাইলে নিজের ভাগ দিতে পারেন (`category.filters`)।
- উপরের দ্রুত চিপ মালিক বাছেন (`category.toolbar`): যে চিপ সব পণ্য বা কোনো পণ্যই মেলায় না, সেটা দেখায় না।
- শিট বন্ধ হয় Esc, বাইরে চাপ বা ✕ দিয়ে; ফোকাস ফিল্টার বাটনে ফেরে। কিবোর্ডে পুরোটা চলে।
