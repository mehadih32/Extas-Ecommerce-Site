ফোন 390×844, ডেস্কটপ 1366×900। এই তিনটা পাতা ডেমোতে নেই, তাই এগুলো ডেমোর প্রোডাক্ট পাতার (`#/admin/products`)

সাইট। সব ছবি নমুনা ডেটা দিয়ে তোলা; একটা নমুনা প্রোডাক্ট বিক্রি বন্ধ করে তিনজন নমুনা কাস্টমারের অনুরোধ রাখা হয়েছে।

## তুলনার ফল

- সব ছবিতে (৩ পাতা × ফোন/ডেস্কটপ × বাংলা/ইংরেজি, আর লিংক পড়ার পরের অবস্থা) পাশে সরে যাওয়া (horizontal scroll) ০, পাতায় কোনো ভুল (error) ০।
- ফোনে উপরের বার, চিপের সারি, শিরোনাম, দুই কলামের সংখ্যার কার্ড আর কার্ডের তালিকা ডেমোর প্রোডাক্ট পাতার মাপেই।
- প্রোডাক্ট পাতা নিজে বদলানো হয়নি (ফোনে ডেমোর মতোই থাকে); নতুন পাতাগুলোতে যাওয়া যায় উপরের চিপ আর মেনু থেকে।
- পেজ রিডারের চাবি/সংযোগ এখনো চালু হয়নি, তাই ছবিতে নমুনা পেজ (mock) — "চাবি ও সংযোগ" পাতায় চালু করলে আসল পেজ পড়বে।
