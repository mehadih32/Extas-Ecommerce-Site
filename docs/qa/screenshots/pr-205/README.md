## পরীক্ষার ফল

- ফোনে কোনো পাতাই পাশে সরে না (horizontal scroll ০)। উপরের মেনুর বোতামগুলো আগের মতোই পাশে টেনে দেখা যায়।
- সব বোতাম আর লিংক আঙুলে চাপার মতো বড় (২৪ px-এর কম কিছু নেই)।
- কোনো পাতায় কাঁচা চাবি-লেখা (যেমন `stock.…`) দেখা যায়নি; ERP-এর মেলানোর ফলও বাংলায় লেখা।
- স্ক্যানের পর লেখার ঘরে আবার কার্সর চলে আসে, তাই স্ক্যানার দিয়ে একটার পর একটা স্ক্যান করা যায়।
- ফোনে একটা ৪০৪ এসেছে শুধু ব্রাউজারের ছোট আইকনের (favicon) জন্য। সাইটের আইকন এখনো বসানো হয়নি, এটা এই PR-এর কাজ নয়।
