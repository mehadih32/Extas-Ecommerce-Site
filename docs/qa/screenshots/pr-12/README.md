## মাপের ফল

- কোনো ছবিতে পাতা পর্দার চেয়ে চওড়া হয়নি, কনসোলে কোনো ভুল নেই, কোনো রিকোয়েস্ট ব্যর্থ হয়নি (ভুল ঠিকানার পাতা ইচ্ছে করে 404 দেয়)।
- "/" আর Ctrl K দুটোতেই সার্চ খোলে, Esc দিলে বন্ধ হয়। অন্য পাতায় গেলে অপেক্ষার সংখ্যা থাকে, ফোনের মেনু বন্ধ হয়।
- ডিভাইস গেট (সাইন-ইন করে, নমুনা ডেটায়): সব ফোন, ট্যাবলেট আর কম্পিউটার সাইজে 0 ভুল।
