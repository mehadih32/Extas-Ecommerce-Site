# PR 41 — হোম পেজ: ছবি

ফোন 440×956 আর 390×844, ডেস্কটপ 1366×900। "app" মানে আসল সাইট, "demo" মানে অনুমোদিত ডেমো **V12.1**।
সব ছবি নমুনা ডেটা দিয়ে তোলা (নমুনা দোকানের ১৭টা পণ্য, নমুনা রিভিউ); মালিকের কোনো তথ্য নেই।

| ছবি | কী দেখাচ্ছে |
|---|---|
| `demo-home-en-*.png` | ডেমোর হোম পেজ — যার সাথে মেলানো হয়েছে |
| `app-home-en-*.png`, `app-home-bn-*.png` | আসল হোম পেজ, ইংরেজি আর বাংলায়: উপরের বড় প্যানেল (লেখা, দুইটা বাটন, প্রতিশ্রুতির লাইন), "ক্যাটাগরি" টাইল, "নতুন এসেছে" কার্ড, "কাস্টমাররা যা বলছেন" |
| `app-card-saved-440.png` | কার্ডের হার্টে চাপ দিলে লাল হয়, নিচে "Saved to wishlist" লেখা আসে; আবার চাপলে সরে যায় |

## কী আছে, কী পরে আসবে

- উপরের প্যানেলের সব লেখা, বাটন (১–৩টা, লেখা, ঠিকানা, ধরন) আর প্রতিশ্রুতির লাইন সেটিং থেকে আসে (`home.hero`)। "ক্যাশ অন ডেলিভারি" আর "এক্সচেঞ্জ" লাইন তখনই দেখায় যখন সেই নিয়ম চালু।
- ডানের চলমান পণ্যের ছবি (হিরো স্লাইডার) PR 43-এ আসবে; ততদিন প্যানেলে শুধু লেখা।
- কোন অংশ দেখাবে আর কোন ক্রমে — সেটিং `home.sections` (পরে পেজ বিল্ডার, PR 595, এটাই বদলাবে)।
- সেট ও কম্বো, "লুক", সাইজ খোঁজা, ফ্ল্যাশ সেল আর জার্নাল — যার যার PR এলে নিজে থেকে দেখাবে (S03, PR 58, PR 44, S12)। এখন দেখানোর মতো সত্যি কিছু নেই, তাই খালি ঘর দেখায় না।
- রিভিউ: শুধু অনুমোদিত রিভিউ; গড় তারা সব অনুমোদিত রিভিউ মিলিয়ে, বেছে নেওয়া রিভিউ দিয়ে নয়। ডেমোর "উচ্চতা · ওজন · সাইজ" লাইনের জন্য ডেটাবেসে ঘর লাগবে (স্কিমার মালিককে জানানো হয়েছে); ততদিন বানিয়ে লেখা হয় না।
- কার্ডে ছবি না থাকলে পোশাকের আঁকা ছবি তার নিজের রঙে; মালিক ছবি দিলে ছবি দেখায়।

## তুলনার ফল

- ফোন 440 আর ডেস্কটপ 1366-এ হোমের প্রতিটা অংশ ডেমোর সাথে মাপা হয়েছে (মাপ, ফাঁক, অক্ষর, রং): ফারাক শুধু নমুনা ডেটার কারণে (কোন পণ্য আগে, কয়টা রং)। হিরো স্লাইডার PR 43-এ।
- দামের "৳" চিহ্ন এখন প্রথমবারেই ডেমোর ফন্টে আসে (২.৫ KB-এর ছোট ফন্ট ফাইল), আগে ফোনের নিজের ফন্টে আসত।
- ডিভাইস গেট: দোকানের ৬টা পাতায় ১৮৬ বার পরীক্ষা — ০ ভুল। ছোট ফোনে (৩২০–৩৭৫ px) চার রঙের কার্ডে "Regular fit" আর কাটা পড়ে না: দরকার হলে নিচের লাইনে যায়।
- ডেস্কটপ মেনুতে ক্যাটাগরিগুলো আবার দেখা যায় (PR 85-এর অদৃশ্য আঙুলের ঘর মেনুর মাপে ভুল ধরাত, তাই সব "More"-এ চলে যেত)।
