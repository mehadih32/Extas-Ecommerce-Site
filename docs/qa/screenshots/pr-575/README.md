# PR 575 — পিসের ছবি দিয়ে নিজে থেকে সেটের ছবি: ছবি

ফোন 390×844, ডেস্কটপ 1366×900। পোলো আর চিনোর ছবি দুইটা শুধু এই ছবির জন্য আঁকা (আসল ছবি নয়), রিপোতে নেই।
মালিক নিজের প্রোডাক্টের ছবি প্রোডাক্ট পাতায় দেবেন; প্রতিটা রঙের সামনের ছবি থাকলেই সেটের ছবি বানানো যায়।

| ছবি | কী দেখাচ্ছে |
|---|---|
| `card-before-bn-390.png` | কম্বো কার্ডে "বদলান"-এর পাশে নতুন বোতাম; ছবি আগে থেকে থাকলে বোতাম বলে "আবার ছবি বানান" (না থাকলে "সেটের ছবি বানান") |
| `card-after-bn-390.png` / `card-after-bn-1366.png` | বোতাম চাপার পর: পোলো বাঁয়ে, চিনো ডানে একটু নিচে (টপ + বটম সাজানো), একই ঘরের রঙের পেছনে; নিচে জানানো "সেটের ছবি বানানো হলো" |
| `page-bn-390.png` / `page-bn-1366.png` | পুরো "নির্দিষ্ট কম্বো" পাতা |

## কীভাবে সাজায়

- ২ পিসের জোড়া: পাশাপাশি। টপ + বটম সেট: টপ বাঁয়ে, বটম ডানে একটু নিচে। ৩ পিস: বাঁয়ে একটা বড়, ডানে দুইটা ছোট।
  ৪ বা বেশি: দুই সারিতে।
- ছবির মাপ, পেছনের রঙ, ফাইলের ধরন আর মান — সব সেটিংস থেকে (`combos.photo.*`)। ছবিতে কোনো লেখা বসানো হয় না;
  "২ পিস" আর "বাঁচে ৳…" পাতার ওপরে আলাদা লেবেল।
- কোনো পিসের সেই রঙের ছবি না থাকলে ছবি বানানো হয় না, কোন পিসের ছবি নেই তা বলে — ভুল রঙের ছবি কখনো দেখায় না।
- আবার বানালে নতুন ফাইল হয়; পুরোনোটা লাইব্রেরিতে থেকে যায় (কিছু মোছা হয় না)।
