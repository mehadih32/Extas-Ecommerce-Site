## তুলনার ফল

- ফোনে উপরের বার, শিরোনাম, কার্ড, সারি, বোতাম আর চাবির ঘর ডেমোর মাপেই আছে। পাশে সরে যাওয়া (horizontal scroll) ০।
- ডেস্কটপে বাঁ মেনু ২৪০ px, লেখা আর কার্ড ডেমোর জায়গাতেই।
- যেটুকু আলাদা, তার কারণ:
  - Azure-এর চাবির ঘরে ৪টা ঘর আছে (ডেমোতে ১টা), তাই ঘরটা একটু লম্বা।
  - "পরীক্ষা" বোতামটা বাড়তি, কারণ রেজিস্টারে চাওয়া হয়েছে।
  - "সিস্টেম" ট্যাবে এখন একটাই পাতা, তাই ট্যাবটা বাঁ দিকে বসেছে।
  - ফোনে "চাবি যোগ করুন" বোতাম ৭ px চওড়া।
