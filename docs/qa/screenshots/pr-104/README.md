## হিসাব কীভাবে

- বিক্রি, টাকা আর বাঁচানো টাকা শুধু আসল অর্ডার থেকে; বাতিল বা ফেরত অর্ডার ধরা হয় না। একটা অর্ডারে একটা সেট = একটা বিক্রি।
- দেখা, রং বাছা আর ব্যাগে নেওয়া — ঘটার সাথে সাথে দিনে দিনে গোনা হয় (দোকানের সময় অঞ্চলে)। একই সেট দুইবার চাপলে একবারই গোনা।
- কতদিন দেখাবে (`combos.report.defaultDays`) আর কয়টা নাম দেখাবে (`combos.report.topCount`) — সেটিংসে বদলানো যায়।
