## মাপের ফল

- কোনো ছবিতে পাতা পর্দার চেয়ে চওড়া হয়নি, কনসোলে কোনো ভুল নেই, কোনো রিকোয়েস্ট ব্যর্থ হয়নি।
- জানালা Esc, ক্রস বোতাম বা বাইরে চাপ দিলে বন্ধ হয়; ফোকাস আবার খোঁজার বোতামে ফেরে। Enter চাপলে ফলাফলের পাতা খোলে।
- নমুনা দোকানে ডেলিভারির রুল এখনো খসড়া, তাই ডেলিভারির পাতা "শিগগিরই আসছে" বলে আর সার্চে আসে না।
