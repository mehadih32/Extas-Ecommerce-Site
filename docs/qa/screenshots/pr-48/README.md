## কীভাবে কাজ করে

- ফোনে ফিল্টার, সাজানো আর "সেলে আছে" বার হেডারের ঠিক নিচে আটকে থাকে; ফিল্টার বাটনের সংখ্যা বলে কয়টা ফিল্টার চালু।
- ডেস্কটপে বাছাই করা ফিল্টার গ্রিডের উপরে দেখায় (প্রতিটার ✕ আর "সব মুছুন")।
- বাংলায় বা লম্বা লেখায় বারের লেখা জায়গা না পেলে নিজে একটু ছোট হয়, তবুও না ধরলে সামনের দুইটা আইকন সরে যায় — লেখা কখনো কাটা পড়ে না।
- ট্যাবলেটে (ডেস্কটপ সাজ, আঙুলে চাপ) সাইজ, রঙের ঘর আর সাজানোর বাটন ৪৪ পিক্সেল উঁচু হয়, যাতে আঙুলে চাপা যায়।
