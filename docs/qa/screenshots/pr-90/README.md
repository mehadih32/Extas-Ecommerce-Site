বানানো; মালিক নিজের কম্বো আর দাম `/admin/combos` পাতায় লিখবেন।

## মাপের ফল

- সব ছবিতে পাশে সরে যাওয়া (horizontal scroll) ০। ৪৪ px-এর ছোট বোতাম বা ঘর ০। কাঁচা লেখা-চাবি (যেমন `combos.…`) ০।
- ফোনে উপরের বার, ট্যাব, শিরোনাম, "নতুন নির্দিষ্ট কম্বো" বোতাম আর কার্ড ডেমোর ক্রমেই আছে; ডেস্কটপে কার্ড তিন কলামে — ডেমোর মতোই।
- যেটুকু আলাদা, তার কারণ:
  - সেটের ছবি এখনো আঁকা রঙের প্যানেল; পিসের ছবি থেকে আসল সেটের ছবি PR 575-এ আসবে।
  - "কম্বো পেজ দেখুন" লিংকের বদলে শুধু ঠিকানা লেখা, কারণ দোকানের কম্বো পেজ পরের PR-এ (S03 স্টোরফ্রন্ট) আসবে।
  - "সেট পেজের লেআউট" ঘর আর অটো কম্বোর ট্যাব PR 571-এ আসবে; "কাস্টমার কী মিলিয়ে নিতে পারে" PR 99-এ।
  - ব্রাউজারের কনসোলে একটাই ভুল: `/favicon.ico` পাওয়া যায়নি — এটা দোকানের আইকনের কাজ, এই PR-এর নয়।
