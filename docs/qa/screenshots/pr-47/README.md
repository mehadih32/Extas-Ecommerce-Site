## কীভাবে কাজ করে

- এটা নিজের বানানো তালিকা (listbox), ব্রাউজারের `select` নয়। তীর, Home, End দিয়ে চলে; Enter বাছে; Esc আর Tab বন্ধ করে, ফোকাস বাটনে ফেরে।
- অপশন আর তাদের ক্রম মালিকের (`category.sort`): ডিফল্ট Recommended, দাম কম→বেশি, বেশি→কম, সেরা রেটিং; "নতুন আগে" যোগ করা যায়। নাম নিজের মতো দেওয়া যায়।
- দাম ছাড়া পণ্য দামের সাজে সবসময় শেষে; সমান হলে মালিকের ক্রম থাকে। রেটিং ছাড়া পণ্য "সেরা রেটিং"-এ শেষে।
