## গ) যা পরীক্ষা করা যায়নি, আপনি কীভাবে দেখবেন

- আসল ব্রাউজারে ডেমো ক্যাটালগ বসানো: Settings (Products) > Demo products-এ ডেমো সুইচ চালু করুন, তারপর "Add the demo catalogue (72 products)" চাপুন। তারপর দোকানের পেজে 72টা প্রোডাক্ট, রঙ, সাইজ আর স্টক দেখুন।
- প্র্যাকটিস ডাটা: Settings > Practice data থেকে PIN দিয়ে রিসেট করুন। আমি এটা চালাইনি।
- Start fresh: লিখিত OK ছাড়া চালানো হবে না।
- ফোন সাইজে লম্বা বোতাম ঠিকমতো ভাঁজ হয় কিনা: CSS আছে, কিন্তু আমি নিজে ফোনে দেখিনি।
- PR 708-এর সম্পূর্ণ CI আর device-gate ফল: শেষ হওয়ার পর দেখতে হবে।
