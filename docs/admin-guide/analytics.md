## সুইচ আর সংখ্যা (ডিফল্টসহ)

- RTO cost book — ডিফল্ট বন্ধ। প্রতি RTO খরচ: কুরিয়ার ৳110 + প্যাকেজিং ৳35 + স্টাফ ৳40 = ৳185; জেলা, ক্যাম্পেইন, পণ্য, কুরিয়ার আর কারণ অনুযায়ী ভাগ। সব সংখ্যা বদলানো যায়।

## তারপর কী হয়
