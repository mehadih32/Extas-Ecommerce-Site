# মেসেজ — সেকশনের সারকথা

কাস্টমারকে অর্ডারের প্রতিটা ধাপে যে SMS, WhatsApp আর ই-মেইল যায় — কোন ধাপে, কোন মাধ্যমে, কোন লেখায় — এখানে ঠিক হবে।

**এই সেকশনের পাতা:** এখনো কোনো পাতা তৈরি হয়নি (পেছনের ব্যবস্থা তৈরি, পাতা পরের ধাপে)। সেকশনটা খুললে লেখা থাকে কোন
পাতাগুলো আসবে।
