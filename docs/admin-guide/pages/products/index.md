# প্রোডাক্ট — সেকশনের সারকথা

দোকানের সব প্রোডাক্ট, কম্বো, স্টক আর সাইজ চার্ট এখানে। নাম-কাপড়-রং-সাইজ-দাম-ছবি দিয়ে প্রোডাক্ট বানানো, চেকলিস্ট পুরো
হলে দোকানে তোলা, আর স্টক ERP থেকে ঠিক আসছে কি না দেখা। **স্টকের আসল হিসাব ERP-তে**, এখানে শুধু দেখা যায়।

- [নতুন প্রোডাক্ট](new.md) — খসড়া প্রোডাক্ট বানানো (`/admin/products/new`)

- [চালুর অপেক্ষায়](queue.md) — যা এখনো দোকানে ওঠেনি (`/admin/products/queue`)
