# কম্বো আর সেট

## এটা কী
২–৩ পিসের কম্বো বানানো, দাম বসানো, চালু/বন্ধ করা, সেটের ছবি আর কম্বোর বিক্রির রিপোর্ট — এক পাতায়, কয়েকটা ট্যাবে।

## কেন দরকার
একসাথে কিনলে কাস্টমার বাঁচান, দোকানের প্রতি অর্ডারে বেশি পিস যায়। রং মিলিয়ে নিজে থেকে জোড়া হয়, তাই প্রতিটা জোড়া হাতে বানাতে হয় না।

> [!NOTE]
> "যেকোনো ২টা পোলো" কম্বো: **কম্বো বানান** চেপে ক্যাটাগরি **পোলো**, **২ পিস**, রং মিলিয়ে জোড়া, দাম (মালিক যা ঠিক করেছেন),
> তারিখ, নাম আর পাতা দিয়ে সেভ করুন। প্রতিটা ধাপে সাথে সাথে গোনা হয় কয়টা জোড়া হবে।

## কীভাবে করবেন
1. **প্রোডাক্ট → কম্বো আর সেট** খুলুন।
2. নতুন কম্বোর জন্য **কম্বো বানান** চাপুন।
3. উইজার্ডের ধাপগুলো পেরোন: ক্যাটাগরি বা প্রোডাক্ট → ২ না ৩ পিস → কীভাবে জোড়া → দাম → তারিখ → নাম → পাতা → দেখে সেভ।
4. তালিকায় কম্বোর **চালু বা বন্ধ** সুইচ দিয়ে দোকানে তুলুন বা নামান।
5. দোকানের লিংক লাগলে **লিংক কপি**; পরে বদলাতে **বদলান**।
6. বিক্রি দেখতে **রিপোর্ট** ট্যাব খুলুন।

## প্রতিটা বোতাম আর ঘরের মানে
- **কম্বো বানান** (Make a combo) — ৮ ধাপের উইজার্ড।
- **দোকানের ডিফল্ট ডিজাইন** (Shop default templates) — **কম্বো ক্যাটাগরি পেজ**, **কম্বো প্রোডাক্ট পেজ**, **ব্যাগে কম্বো কেমন দেখাবে**।
- **কম্বো রুল** (Combo rules) — প্রতিটা রুল কয়টা জোড়া বানিয়েছে, কয়টায় স্টক আছে।
- **চালু বা বন্ধ** (on or off) — রুল দোকানে চালু কি না।
- **শুরু / শেষ** (Starts / Ends) — কবে থেকে কবে পর্যন্ত চলবে।
- **পেজ / জোড়ার পেজ** (Page / Pair page) — কম্বো কোন ধরনের পাতায় দেখাবে।
- **"আরও ১টা নিন → ৩ পিস"** (Add 1 more → 3 pcs) — ২ পিসের কম্বোতে তৃতীয় পিস যোগের অফার।
- **লিংক কপি** (Copy link) — কম্বো পাতার লিংক।
- **বদলান** (Edit) — কম্বো বা রুল বদলানো।
- **সেটের ছবি বানান** (Make set photo) — প্রতিটা পিসের সেই রঙের ছবি মিলিয়ে একটা ছবি।
- **আর্কাইভ** (Archive) — শেষ বা বন্ধ করা রুল; আবার চালু করলে একই লিংক ফেরে।
- **রিপোর্ট** (Report) — দেখা, ব্যাগে নেওয়া, অর্ডার, **অর্ডারের মূল্য**, **বিক্রি (ডেলিভারি হওয়া)**, কাস্টমারের বাঁচানো টাকা।
- **আরও** (More) — সেকশনের বাকি ট্যাব।

## সাধারণ ভুল
- **সেটের দাম আলাদা দামের সমান বা বেশি রাখা।** তখন আলাদা দামই নেওয়া হয় আর "বাঁচে" দেখায় না।
- **"যেকোনো ২টা"-র দাম এখানে খোঁজা।** সেটা [স্মার্ট নিয়ম](../marketing/rules.md)-এ (মালিকের অনুমতি লাগে)।
- **কোনো পিসের ছবি ছাড়া সেটের ছবি বানানো।** কোন পিসের ছবি নেই, তা বলে দেয় — আগে সেই ছবি দিন।

> [!WARNING]
> সেটের দাম বসাতে "সেটের দাম" অনুমতি লাগে — দাম মালিকের সিদ্ধান্ত।

## এরপর কী হয়
চালু কম্বো দোকানে বিক্রি হয়; দোকানের পাতা, ব্যাগ আর চেকআউট একই দাম নেয়। বন্ধ করলে আর্কাইভে যায়, পাতা খোলা থাকে আর
"অফার শেষ" বলে। রিপোর্টে শুধু ডেলিভারি হওয়া অর্ডারই বিক্রি।
