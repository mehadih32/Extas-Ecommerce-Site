# সাহায্য আর অগ্রগতি — সেকশনের সারকথা

অ্যাডমিনের সব গাইড এক জায়গায়, বাংলায়। প্রতিটা পাতার নিজের গাইড উপরের বারের ছোট **?** আইকন থেকেও খোলে।

**এই সেকশনের পাতা:**
- [সাহায্য আর ম্যানুয়াল](manual.md) — প্রতিটা সেকশন, তার গাইড আর তৈরি কি না (`/admin/help`)
- [সাইট ম্যানুয়াল](site-manual.md) — পুরো অ্যাডমিন একটা বই: প্রতিটা সেকশন একটা অধ্যায়, প্রতিটা পাতার গাইড তার ভেতরে (`/admin/help/manual`)

পরে আসবে: কাজের অগ্রগতি (PR-এর তালিকা, শুধু মালিক)~~, "নতুন কী এলো"~~। "নতুন কী এলো" এখন সাইট ম্যানুয়ালের উপরে (PR 389)।
