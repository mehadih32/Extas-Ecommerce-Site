# সাপোর্ট — সেকশনের সারকথা

কাস্টমারের প্রশ্ন, অভিযোগ আর এক্সচেঞ্জের অনুরোধ এক জায়গায় আসবে, কে কোনটা দেখছে আর কতক্ষণ অপেক্ষায় — সহ।

~~**এই সেকশনের পাতা:** এখনো কোনো পাতা তৈরি হয়নি। সেকশনটা খুললে লেখা থাকে কোন পাতাগুলো আসবে।~~

**এই সেকশনের পাতা (PR 425):**
- [ইনবক্স](inbox.md) — সব চ্যানেলের কথোপকথন এক তালিকায়, ভিউ আর খোঁজা (`/admin/support`)
- [কথোপকথন](conversation.md) — পুরো কথা, উত্তর আর ভেতরের নোট, ফাইল, দায়িত্ব, অবস্থা আর লগ (`/admin/support/c/[id]`)
- [সাপোর্ট সেটিংস](settings.md) — ইনবক্সের নিয়ম, কাস্টমারের নম্বর লুকানো, ফাইলের নিয়ম (`/admin/support/settings`)
- [রাইডারের সমস্যা](rider-issues.md) — রাইডার বেশি টাকা নিলে ছবি-প্রমাণসহ লেখা, মেনে নিলে কুরিয়ারে ক্লেইম (PR 192, `/admin/support/rider-issues`)
