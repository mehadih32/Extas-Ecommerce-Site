# রিপোর্ট — সেকশনের সারকথা

বিক্রি, অর্ডার, কুরিয়ার আর ফেরতের রিপোর্ট, আর সাইটের নিজের অবস্থা। এখন তৈরি শুধু সাইটের অবস্থার পাতা।

**এই সেকশনের পাতা:**
- [সাইটের অবস্থা — এক নজরে](health.md) — কাস্টমারের সমস্যা, সার্ভার, গতি, সাইট অডিট আর স্মোক টেস্টের একটা করে লাইন (`/admin/reports/health`)
- [সাইটের অবস্থা](server.md) — সার্ভার আর পেছনের কাজ চলছে কি না (`/admin/server`)

পরে আসবে: বিক্রি আর অর্ডারের রিপোর্ট, RTO-র খরচ, কুরিয়ার অনুযায়ী সফলতা।
বড় গাইড: [সার্ভার](../../server.md) · পরিকল্পনা: [রিপোর্ট](../../analytics.md)।
