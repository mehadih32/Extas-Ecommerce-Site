# কাস্টমার — সেকশনের সারকথা

কাস্টমারের তালিকা, প্রতিটা কাস্টমারের অর্ডার আর কথাবার্তা, পয়েন্ট আর ওয়ালেট — সব এক জায়গায় থাকবে।

**এই সেকশনের পাতা:** এখনো কোনো পাতা তৈরি হয়নি। সেকশনটা খুললে সৎভাবে লেখা থাকে "পরের ধাপে এখানে আসছে" আর কোন পাতাগুলো
আসবে। পাতা তৈরি হলে তার গাইড এখানে যোগ হবে।
