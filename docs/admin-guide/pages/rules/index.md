# নিয়ম (Rules) — সেকশনের সারকথা

দোকানের সব নিয়ম এক জায়গায়: দোকান নিজে কী করবে (**স্মার্ট নিয়ম**), কাস্টমারকে কী দেখানো হবে (**নোটিশ ও পপ-আপ**),
আর ঈদের শেষ অর্ডারের দিন (**ঈদের তারিখ**)। আগে এগুলো মার্কেটিংয়ের প্রথম ট্যাব ছিল; PR 659-এ আলাদা **Rules** সেকশন হয়েছে।
পাতার ঠিকানা আগের মতোই, কিছু মোছা হয়নি। টাকার নিয়ম চালু করতে মালিকের অনুমতি লাগে।

**এই সেকশনের পাতা:**
- [স্মার্ট নিয়ম](rules.md) — নিয়ম লেখা, দেখে নেওয়া, প্রকাশ, ইতিহাস (`/admin/rules`)
- [নোটিশ ও পপ-আপ](notices.md) — উপরের বার আর পপ-আপ (`/admin/rules/notices`)
- [ঈদের তারিখ](eid.md) — ব্যান্ড আর জেলা অনুযায়ী ঈদের শেষ অর্ডারের দিন, "ঈদের পরে পৌঁছাতে পারে", অগ্রিমসহ প্রি-অর্ডার (`/admin/rules/eid`)

বড় গাইড: [স্মার্ট নিয়ম আর নোটিশ](../../rules.md)।
