# সার্ভার

ঠিকানা: `#/admin/server`

## এই সেকশন কিসের জন্য

- প্রতিটা অংশের মেমরি আর প্রসেসর, ডিস্ক, দ্রুত অস্থায়ী ডিস্ক, ক্যাশ আর ধীর কোয়েরি — সহজ ভাষায়।

## মেনু আর ট্যাব

- উপরের ট্যাব: Server, Cache, Images, Speed, Backup, Keys & connections

## এখানে কী করা যায়

- অবস্থা দেখা, টেস্ট সতর্কতা পাঠানো

## সুইচ আর সংখ্যা (ডিফল্টসহ)

- ডিস্ক 80%-এর বেশি ভরলে, কোনো সার্ভিস 2 মিনিট বন্ধ থাকলে, ব্যাকআপ 1 বার ব্যর্থ হলে, সাইট 1500 ms-এর বেশি ধীর হলে সতর্কতা

## তারপর কী হয়

- সমস্যা হলে Telegram-এ মেসেজ যায়।
