# বদল আর ফেরত

ঠিকানা: `#/admin/exchanges`

## এই সেকশন কিসের জন্য

- কাস্টমার অ্যাকাউন্ট থেকে যে অনুরোধ পাঠায়। সাইজ বা ত্রুটির জন্য সময়ের মধ্যে বদল; ডেলিভারির পর ফেরত নেই।

## মেনু আর ট্যাব

- Exchange requests, Return requests, Receive & QC, Done
- নতুন: "Optional features in this section" — One-trip size swap

## এখানে কী করা যায়

- অনুমোদন দিয়ে বদল বুক করা, কারণসহ না করা
- ফেরত আসা জিনিস QC করা

## সুইচ আর সংখ্যা (ডিফল্টসহ)

- বদলের চার্জ স্মার্ট রুলস থেকে (ঢাকা ৳80, বাইরে ৳120)
- One-trip size swap — ডিফল্ট বন্ধ। চালু হলে: চার্জ ৳80, ডেলিভারির 3 দিনের মধ্যে, এলাকা: Dhaka city, Gazipur, Narayanganj, Savar

## তারপর কী হয়

- One-trip swap চালু থাকলে কাস্টমারের বদলের পেজে অপশনটা দেখায়; রাইডার নতুন সাইজ দিয়ে পুরনোটা একই যাত্রায় নেয়।
