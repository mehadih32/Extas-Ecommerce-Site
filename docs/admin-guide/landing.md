# ল্যান্ডিং পেজ

ঠিকানা: `#/admin/landing`

## এই সেকশন কিসের জন্য

- Facebook/TikTok/Google বিজ্ঞাপনের জন্য এক পণ্য, এক লক্ষ্য, পেজেই অর্ডার ফর্ম।

## মেনু আর ট্যাব

- পেজের তালিকা
- বাটন: Create landing page, Open page, Copy link

## এখানে কী করা যায়

- নতুন পেজ বানানো
- লিংক কপি করে বিজ্ঞাপনে দেওয়া
- A/B টেস্ট চালু করা

## সুইচ আর সংখ্যা (ডিফল্টসহ)

- A/B test — প্রতিটা পেজে ডিফল্ট বন্ধ

## তারপর কী হয়

- পেজ থেকে আসা অর্ডার "Orders"-এ আসে, উৎস হিসেবে ল্যান্ডিং পেজ লেখা থাকে।
