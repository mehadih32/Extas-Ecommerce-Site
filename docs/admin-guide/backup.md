# ব্যাকআপ

~~ঠিকানা: `#/admin/backup`~~ (ডেমোর পুরনো ঠিকানা)। এখন: **সেটিংস** › **সিস্টেম** › **ব্যাকআপ** (`/admin/settings/system/backups`), PR 395 (CN-030)। পাতার গাইড: [ব্যাকআপ](pages/settings/backups.md).

## এই সেকশন কিসের জন্য

- পুরো দোকান প্রতি রাতে দুই জায়গায় কপি হয় — Azure Blob আর Google Drive (এনক্রিপ্ট করা)।

## মেনু আর ট্যাব

- Google Drive, Azure Blob, Schedule & retention, Monthly restore test, Last runs

## এখানে কী করা যায়

- এখনই ব্যাকআপ নেওয়া
- রিস্টোর টেস্ট চালানো
- ব্যাকআপ থেকে ফেরানো: আগে পরীক্ষার কপিতে, পাস করলে একই ব্যাকআপ আসল দোকানে (RESTORE লিখে আর মালিকের PIN দিয়ে; PR 396)
- আসল অর্ডারের আগে ব্যাকআপ তৈরি কি না দেখা (8টা যাচাই; PR 391)
- কোন জিনিস ব্যাকআপে যাবে বাছা
