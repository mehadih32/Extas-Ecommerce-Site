# AI আর এজেন্ট

ঠিকানা: `#/admin/ai`

## এই সেকশন কিসের জন্য

- AI কী করবে, কোন কোম্পানির কোন মডেল, কখন চলবে আর কত খরচ করতে পারবে — সব আপনি ঠিক করেন। AI বন্ধ থাকলেও দোকান চলে।

## মেনু আর ট্যাব

- Control room, Model picks, Spend caps, Data routing, Cost book, AI media library

## এখানে কী করা যায়

- প্রতিটা এজেন্ট চালু/বন্ধ করা
- মাসিক খরচের সীমা দেওয়া
- Run the AI-off test চালিয়ে দেখা দোকান AI ছাড়া চলে কিনা

## সুইচ আর সংখ্যা (ডিফল্টসহ)

- EXTAS AI master switch — চালু
- Cost-saver — চালু

- Customer Support Agent — ৳1,200/মাস

## তারপর কী হয়

- খরচ সীমা ছুঁলে AI থেমে যায় আর আপনাকে জানায়; দোকানের কাজ সাধারণ নিয়মে চলতে থাকে।
