# একসাথে অনেক কাজ

ঠিকানা: `#/admin/bulk`

## এই সেকশন কিসের জন্য

- অনেক অর্ডারে টিক দিয়ে একবারে কনফার্ম, কুরিয়ার বুক বা প্রিন্ট।

## মেনু আর ট্যাব

- Orders, Confirm, Book courier, Stickers, Picking list, Invoices

## এখানে কী করা যায়

- টিক দিয়ে একসাথে কাজ

## সুইচ আর সংখ্যা (ডিফল্টসহ)

- ডুপ্লিকেট বা ফ্রড রিভিউতে থাকা অর্ডার কেউ সিদ্ধান্ত না দেওয়া পর্যন্ত বাদ থাকে।

## তারপর কী হয়

- কাজ শেষে অর্ডারের স্ট্যাটাস বদলায়।
