# P04 · Set / combo photos — showing 2–3 pieces together

*Shilpi শিল্পী · A360-05 · photo module 4 of 6 · version 1.0 · as of October 2026*
*Supports PR 575 (set composition) and Sawdagor's combo pages (S02). Combos are central to EXTAS's offer.*

---

## 1. Why sets need their own photo
- A combo is sold as **one product** (own catalogue ID, price, page — Tirondaj T01 §3). A catalogue ad or a combo card that shows a single piece with a set price misleads and causes refusals.
- Blueprint: "Combos are central to this business, yet there is no way to photograph a set" → the **combo/gift-set studio**: pick 2–4 products, choose a layout, produce **one clean set image**.

## 2. Layouts (choose per combo type) [HOUSE, from blueprint layouts + photography practice]

| Layout | Best for | Rules |
|---|---|---|
| **Outfit flat lay** (top above bottom, as worn) | polo + jogger, tee + shorts, panjabi + pajama | pieces aligned on a vertical axis, slight overlap at the waist, same light; shoes/cap only if included in the set (or clearly marked "not included") |
| **Stacked / fanned** (same item, multiple colours) | "3 polos" multi-packs | colours fanned so every colour is visible; folded identically; count obvious at thumbnail size |
| **Ghost composite outfit** | premium sets | each piece shot ghost, composited into one outfit silhouette |
| **One model wearing the set** (real or approved AI) | outfit combos | full body, head and feet in frame; all pieces visible; second image shows each piece alone |
| **Side-by-side tiles** (2–3 equal cells) | mix-and-match sets where colours are chosen by the customer | updates with the chosen colours (pre-rendered, never at page-view time) |

## 3. Composition rules
1. **Every included piece fully visible**; nothing included is hidden, nothing not included is shown without a label.
2. **Count readable at thumbnail size** (feed and grid): 3 pieces must look like 3 at 300 px wide.
3. **Same scale** between pieces (a jogger shouldn't look smaller than the polo above it).
4. Frame inside the 4:5 site canvas, crop-safe to 1:1 and 9:16 (P03).
5. **Colour truth**: each piece corrected from its own checker frame before compositing (P02).
6. Optional overlay "৩ পিস" / price only in **ad** versions, never in the catalogue/feed main image.
7. Gallery for a combo page: set photo → model wearing the set → each piece's own front/back → fabric macros. (Owner rule: tapping a piece keeps the customer inside the combo.)

## 4. Testing
The blueprint plans an A/B test of on-model vs flat-lay measuring add-to-bag, conversion and **return/refusal rate**. Run the same for set layouts (outfit flat lay vs model wearing set) on the top 3 combos.

## 5. Checklist
- [ ] One set image per combo (and per colour option if colours are fixed).
- [ ] All pieces visible, same scale, count readable at 300 px.
- [ ] Not-included items absent or labelled.
- [ ] Crops valid at 4:5, 1:1, 9:16; feed variant on plain background.
- [ ] Alt text names every piece (P06).
