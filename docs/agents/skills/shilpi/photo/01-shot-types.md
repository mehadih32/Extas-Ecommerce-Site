# P01 · Shot types for menswear — flat lay, ghost mannequin, on-model (real and AI)

*Shilpi শিল্পী · A360-05 · photo module 1 of 6 · version 1.0 · as of October 2026*
*Shared standard with Bhandari (catalogue & images, S01) and the studio (S24 virtual photoshoot, owned by Gyani).*

---

## 1. The three shot types

| Type | What it is | Strengths | Weaknesses | Evidence |
|---|---|---|---|---|
| **Flat lay** | garment laid flat on a plain surface, shot from above | cheapest, quick, shows colour/print/texture; good DIY for menswear | no fit, no drape, no body | Shopify clothing photography guide (May 2025) |
| **Ghost mannequin** | garment on a mannequin; mannequin removed and the inner neck/back (shot separately on foam board) composited in | worn 3D shape without a model; consistent catalogue look; strong input for AI try-on | needs compositing skill; no "real person" feel | Pixelz workflow; Profoto steps; EXTAS blueprint C7.4/C7.9 |
| **On-model** | real person (or approved AI virtual model) wearing it | shows fit and scale; Baymard: show products on real human models (21% of apparel sites don't) | cost; model consistency; AI fidelity risk | Baymard apparel best practices; Shopify |

## 2. EXTAS shot plan per category (from blueprint C7.9, kept)

| Category | Required set |
|---|---|
| Polo / T-shirt / Shirt / Panjabi | real flat or ghost **front** · 3 model angles (front, three-quarter, back) · **real fabric macro** · details (side tape, vent, collar, placket, cuff, chest logo) |
| Trousers / denim / chino / jogger | ghost front · 2 model angles (full length, walking) · real fabric + hardware macro |
| Hoodie / sweatshirt / jacket | ghost front + back · model front/three-quarter · macro of fleece inside |
| Boxer / underwear | ghost front and back · fabric macro · model **off by default** |
| Combos | set photo (P04) + each piece's own set |

Gallery order (blueprint): **real front shot → on-model views → back → fabric close-up → detail**. The real photo stays the hero; fabric and colour truth come from real photos.

## 3. Ghost mannequin workflow (practical)
1. Mannequin: white, non-reflective, removable neck/chest/arm pieces; garment in the right size for the form.
2. Prep: steam, lint-roll, check loose threads (Shopify).
3. Shot A: garment on mannequin, front (and back). Camera **level with the chest** for tops, hips for bottoms — too high/low makes the garment look tapered; telephoto reduces distortion (Pixelz).
4. Shot B: inner neck/back label on foam board, **same lights, same position marks** (Pixelz).
5. Composite: mask garment, place neck insert behind, add a soft inner shadow, keep a layered master + flattened export.
6. Lighting: two even lights (umbrellas/softboxes) either side, or continuous LED for consistency (Pixelz; Profoto).

## 4. On-model rules
- Same model library per season for consistency (blueprint: M01–M04 identities).
- Model info chip on PDP: height, weight, size worn (Baymard size info; blueprint).
- Poses: front, three-quarter, back, walking; hands not covering logos/pockets.
- **AI virtual model images** (S24): generated from verified references; one job per angle; **mandatory approval**; never claimed as fit evidence; one honest disclosure line in product details (blueprint C7.15). Logos/prints re-projected from the real photo, never re-drawn.

## 5. Phone-shoot discipline when no studio (blueprint C7.4)
Flat-lay on a plain sheet or ghost; even window light, no harsh shadows; phone **parallel** to the garment at the **same distance every time**; a **grey card / colour checker in one frame per colourway**; required set: front, back, detail/fabric, print/label.

## 6. Checklist per product
- [ ] Required shots per category done; nothing missing for any colourway.
- [ ] Garment steamed, centred, no lint, tags hidden (unless a label detail shot).
- [ ] Colour checker frame captured per colourway (P02).
- [ ] Files named per convention (P06) and uploaded as originals (immutable).
