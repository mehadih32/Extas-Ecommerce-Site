# Bhandari ভান্ডারী · pointer — product photo standard

*Curriculum wave 1 · as of October 2026*

The product photography standard lives in **skills/shilpi/photo/** (owned by Shilpi, shared with Bhandari because
Bhandari owns S01 catalogue & images). Load it before any catalogue/image task.

What Bhandari must apply from it:
| Bhandari task | Module |
|---|---|
| Required shots per category before a product can be published | P01 §2, §6 |
| Colour checker frame per colourway; colour word in catalogue matches the corrected photo | P02 |
| Site 4:5 canvas + feed variant (9:11 or 1:1, plain background) for Meta catalogue / Merchant Center; images ≥ 500×500 (Meta) / ≥ 512×512 ideally ≥ 1024 (Google) | P03 |
| Combos as their own catalogue items with a set photo | P04 |
| Derived sizes and formats from the immutable original | P05 |
| Alt text, file names, image sitemap entries | P06 |

Catalogue data rules that depend on images (Tirondaj T01 §3, Doot D02 §4): `item_group_id` across variants, colour in
words, `additional_image_link` (up to 20), custom labels (combo/single, season, margin band, stock band).
