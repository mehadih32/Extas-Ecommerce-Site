## Confidence tags
**[OFFICIAL]** platform documentation · **[2-SRC]** two independent good sources agree · **[HOUSE]** EXTAS rule set from
our own economics/owner guardrails (revisable by data) · **[COMMUNITY — test before use]** single practitioner or forum
claim. Only the first three are rules (PR 585 quality gate). Untagged statements in T01–T04 that cite a platform doc are
[OFFICIAL]; statements labelled "practitioner lore", "reported" or "community" are [COMMUNITY].
