# Tirondaj · Paid tools that would genuinely help (and what the free tools already do)

*PR 585 · prices are listed only when verified on the vendor's own page — none could be verified this session, so none
are quoted; check the vendor page on the day of purchase · as of October 2026*

## Free official tools first (use these before paying for anything)

| Free tool | What it gives EXTAS |
|---|---|
| Meta Ads Manager + Events Manager | all campaign data, EMQ, dedup diagnostics, breakdowns (new/engaged/existing customers) |
| **Meta Ad Library** | every active ad of any BD menswear competitor (creative, start date, platforms) — manual but free |
| Google Ads + Keyword Planner + Performance Planner | search volumes, forecasts, budget modelling |
| Google Merchant Center diagnostics | feed errors, price competitiveness / popular products reports (where available) |
| Google Trends | season curves for "hoodie", "panjabi", "polo shirt" in Bangladesh |
| TikTok Ads Manager + Creative Center | trending sounds, top ads by region/industry |
| GA4 / our own dashboard | delivered ROAS by channel, campaign, district (the source of truth) |
| GeoLift (open source, R) | geo-test design and analysis at zero licence cost |

## Paid tools worth considering (in order of value for EXTAS)

| Tool (type) | What it adds over the free tools | Fit for EXTAS | Trial (verified on vendor page) |
|---|---|---|---|
| **Foreplay** (ad swipe file / ad library) | saves competitors' Meta/TikTok ads permanently (Ad Library loses ads when they stop), boards, brand tracking, briefs | High — creative is our main lever (T05) | **7-day free trial**, "no usage limitations" (Foreplay FAQ) |
| **Motion** (creative analytics) | groups ads by concept/hook/format and shows which creative *traits* win; faster than spreadsheets | Medium–high once we run 30+ ads/month | not verified |
| **Madgicx** (Meta automation + creative insights) | automated rules, creative insights, audience tools for Meta | Medium — our own code already enforces guardrails; overlap risk | not verified |
| **Similarweb** (market intelligence) | competitor traffic sources (paid social vs search vs direct), top referrers, rough traffic size of BD menswear sites | Medium for planning; BD small-site data may be thin | **7-day free trial** (Similarweb support page; billed automatically unless cancelled) |
| **Semrush** (SEO + PPC suite) | competitors' Google Ads keywords and ad copy (where Google ads run in BD), keyword gaps — shared with Doot | Medium (more for Doot) | **7-day free trial** of Pro or Guru (Semrush landing page) |
| Triple Whale / Northbeam (attribution) | multi-touch attribution dashboards | **Low** — built around Shopify/large spend; our DB already does delivered attribution | not verified |

Rule: buy at most **one** paid tool at a time, only after the free tools are used weekly, and only with an owner-approved monthly cost line (money = owner approval).
