## 2. SEO — what South-Asian practice confirms (no new rules)

1. **Start with Search Console, indexing, speed and unique on-page basics; budget 3–4 months** before judging SEO (eChai) — matches D01/D02 **[2-SRC — eChai + Google SEO starter guidance already in D01]**.
2. **Unique product descriptions and unique titles/meta; no keyword stuffing; never copy competitors' copy** (Shiprocket bn, eChai) — Google's spam policy already says it (D03) **[OFFICIAL via D03]**.
3. **Blog posts must target buyer-intent queries and link to collection/product pages**; ~8–10 pillar topics from real demand (eChai) — same direction as D05 **[2-SRC — eChai + D05's Google people-first guidance]**; the "8–10" count is **[COMMUNITY]**.
4. **Skip paid link packages and guest-post farms; earn links via directories/gift guides, product seeding with disclosure, unlinked-mention outreach, digital PR** (eChai) — same as D07 and Google's link-spam policy **[OFFICIAL via D07]**.
5. **Hindi vs Hinglish was important enough for Google to answer in its Hindi series** → reinforces D03: measure the English / বাংলা / Banglish split from our own Search Console data rather than guessing **[HOUSE]**.

## 3. Organic social and brand — Bangladesh practice

- **Facebook page first, website as the destination:** Strides Co built awareness on Facebook/Instagram (~70K followers) for ~1.5 years, then pushed the website as the main shop because it shows size guides, fabric details and stock that a page can't; SEO and an agency came later **[COMMUNITY — one founder interview]** → consistent with EXTAS's plan (site + Facebook), adds one rule of thumb: **every organic post links to a product/combo page on our site, never "inbox for price"** **[HOUSE]**.
- **Social proof, live video, complete Page details, Messenger engagement** for f-commerce trust (DHL BD) **[COMMUNITY — vendor guide]**; EXTAS already plans reviews and WhatsApp.
- **Audience size:** ~60.0 M active social media users and ~77.7 M internet users in Bangladesh in Jan 2025, Facebook the most used platform **[COMMUNITY — DHL citing DataReportal; read DataReportal before quoting]**.

## 5. CRM and COD messaging — where South-Asian practice is strongest

| Practice | Who says it (independent sources) | Tag |
|---|---|---|
| **Confirm every COD order before dispatch** (call, WhatsApp or SMS); cancel if unconfirmable after a set number of attempts | Velocity, eChai, Shipmozo (India); DHL PK, Markaz, Aaj TV (Pakistan); Future Startup (BD) | **[2-SRC]** — EXTAS already confirms every order |
| **Send the confirmation within minutes**, one follow-up, then manual review/auto-cancel; cap at two messages | base.com (vendor) | [COMMUNITY — test] |
| **Quote the full total incl. delivery before dispatch**; clear delivery window + day-before / out-for-delivery alerts | Markaz, DHL PK; Bangladesh DCOG 2021 requires delivery charges shown (Bhandari B07) | **[2-SRC]** |
| **Collect a landmark, second phone and preferred time** | Markaz | [COMMUNITY — test]; landmark field already collapsed in checkout (Shilpi U09) |
| **Follow up failed deliveries (NDR) fast** by WhatsApp/SMS/call before the parcel turns into a return | Velocity, eChai (citing Clickpost), Shipmozo, HillTeck | **[2-SRC]** for the practice; their % recoveries unsourced |
| **Exchange-first returns, self-service via WhatsApp** | DHL PK | [COMMUNITY]; EXTAS is exchange-only already |

### What this changes for Doot's message plan (D09)
- The owner's budget is **2 SMS + 1 WhatsApp per order**. A COD **confirmation** message and an **NDR follow-up** are both strongly supported by practice — but they compete for the same budget. → **Owner decision** (see README): does the confirmation call/message and a failed-delivery follow-up count inside the 2 + 1, or sit outside as operational messages?
- Draft Bengali templates (utility category; owner approves wording):
  - Confirmation: "EXTAS: আপনার অর্ডার #{no} — মোট ৳{total} (ডেলিভারি সহ), ক্যাশ অন ডেলিভারি। ঠিক থাকলে 1, বাতিল করতে 2 লিখুন।"
  - NDR: "EXTAS: আজ ডেলিভারি দিতে পারিনি। কখন দিলে সুবিধা? ঠিকানা/ল্যান্ডমার্ক ঠিক আছে তো? উত্তর দিন — আবার পাঠাচ্ছি।"
- Measure (own data, by channel and district): confirmation rate, refusal rate with/without confirmation reply, NDR recovery rate — these become EXTAS's numbers; no borrowed percentages.
