# Doot · Trial plan — one honest trial, owner's own account, after the site is live

*PR 585 · as of October 2026*

**Rules:** one trial per tool, ever; the owner's own account and card; no repeat or throwaway accounts. Start only
when (a) the site has been live ≥ 6–8 weeks (Search Console has data to compare), (b) Doot's extraction list is ready
with competitor domains and seed keywords, (c) a cancel reminder is set for day 6. Export everything on day 6.

## Semrush — 7-day free trial (Pro or Guru) — shared with Tirondaj
Choose **Guru** only if the content/topic tools are needed; otherwise Pro. Tirondaj takes the PPC half on days 1–2 (see skills/tirondaj/TRIAL-PLAN.md).

| Day | Extract for EXTAS | Output |
|---|---|---|
| 0 (prep) | list 8–10 BD competitor domains (menswear D2C brands, big fashion e-shops; Fabrilife already torn down), 30 seed keywords EN/BN | competitors.txt, seeds.txt |
| 1 | **Domain Overview + Organic Research** for each competitor: top organic keywords (BD database if available), top pages | organic-competitors.xlsx |
| 2 | **Keyword Gap**: EXTAS vs 3–5 competitors → keywords they rank for and we don't (menswear categories, combos, size/fabric questions) | keyword-gap.xlsx |
| 3 | **Keyword Magic Tool**: expand seeds (polo, t-shirt, hoodie, tracksuit, panjabi, combo) → volumes/difficulty for BD; note Bengali coverage quality honestly | keyword-universe.xlsx |
| 4 | **Backlink Gap + Backlink Analytics**: domains linking to competitors but not to us (BD news, blogs, directories worth having, partners) | link-prospects.xlsx |
| 5 | **Site Audit** of extas (full crawl) → issue list with priorities | site-audit.pdf/xlsx |
| 5 | **Position Tracking** baseline for 100 target keywords (record day-5 positions) | baseline-positions.xlsx |
| 6 | Summary: top 20 page opportunities, top 20 link prospects, 10 technical fixes, keyword map update | semrush-summary.md |
| 7 | Owner decides buy/cancel | — |

## Ahrefs — no paid-plan trial confirmed
Use **Ahrefs Webmaster Tools (free)** continuously instead: monthly Site Audit, our own backlinks and keywords. If the
owner later buys Starter ($29/month per vendor page) for one month, extract the same list as Semrush days 1–4.

## Screaming Frog — free version (not a trial)
Use the free 500-URL crawl at launch (D01 §6). Buy a licence only if the crawl needs > 500 URLs regularly.

## Similarweb — 7-day trial (Tirondaj leads)
Doot's part: referral sites and social referrers of competitors → PR and partnership targets (D07).

## After each trial
Store exports; propose skill updates (LEARNING-LOOP); work-log line: date · tool · extracted · decision.
