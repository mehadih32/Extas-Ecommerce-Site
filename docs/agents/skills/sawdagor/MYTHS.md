# Sawdagor · Doesn't work / myths (e-commerce)

| Myth | Evidence | Do instead |
|---|---|---|
| "Decoy pricing reliably pushes customers to the option we want." | The original authors say the attraction effect is rare and fragile in real markets; the compromise effect is more common (Huber et al. 2014). | Honest 3-tier ladders; highlight the middle. |
| "Pure bundles (set only) always earn more." | Mixed bundling dominates when valuations differ / in competitive markets (Stremersch & Tellis 2002). | Sets and singles (outside combo-only sections). |
| "A free-shipping banner is enough." | 27% of test users missed banner-only free-shipping info (Baymard). | Show it near the Buy section with conditions. |
| "Dropdowns save space for sizes." | 70% of apparel sites use non-button size selectors; Baymard recommends buttons. | Size buttons, disabled when out of stock. |
| "More checkout fields = better data." | Average 11.3 fields; most sites need only 8 (Baymard 2024). | ≤ 6–8 fields, infer the rest. |
| "US abandonment stats describe Bangladesh." | Baymard numbers are US/EU; BD is COD-first. | Use as a checklist, measure our own funnel. |
| "Permanent discounts drive trust." | Strikethrough must be a real former price (Google StrikethroughPrice rules); fake urgency erodes trust (NN/g trust topics). | Real prices, real stock messages. |
| "Charm prices always win." | Anderson & Simester found $9 endings raised demand, especially for new items — not a universal law. | Test on new styles with owner-approved prices. |

Sources: see S01–S06.

*As of October 2026.*
