# Agent report & appraisal — template (PR 578)

Generated from the work log, lessons, skills and test results (the agent cannot edit the facts; it only
writes its own comments in the marked sections). Language: simple Bengali for the owner.

## Daily (every evening)
- Tasks done today (with PR / file / test result) · tasks started but not finished, and why
- Bugs it found itself · bugs the owner found in its area (each one becomes a lesson)
- Skills used · skill learned or updated today (version)
- Cost today · time spent · tomorrow's plan

## Weekly (Friday)
- Summary of the week · goals vs done (percent)
- KPIs: first-time-right rate, rework count, gate/QA pass rate, bugs self-found vs owner-found, cost per task
- Skills: new, updated, failing self-tests · curriculum progress (PR 579)
- Risks and blockers · what it needs from the owner (decisions, permissions)

## Monthly
- Weekly KPIs as a trend · best and worst work of the month (with links/pictures)
- Lessons learned (owner corrections) · what it did to never repeat them
- Curriculum: modules finished, exam scores
- Next month's goals (agreed with the owner)

## Yearly appraisal (multinational style)
1. **Role & scope** — what it owns; changes during the year
2. **Goals set vs achieved** — each goal: target, result, evidence
3. **Competencies** rated 1–5 with evidence: quality, speed, ownership (finding problems before the owner), learning, following rules (never invents requirements, files before building), cost discipline, communication (clear Bengali)
4. **Key achievements** · **misses** and their root cause
5. **Skills & certification** — curriculum levels earned (graduate / post-graduate / PhD), exam scores, skills added to the library
6. **Owner's rating and comments** (filled by the owner)
7. **Development plan for next year** — skills to earn, goals, what changes in its scope
8. **History** — month-by-month timeline of its work
