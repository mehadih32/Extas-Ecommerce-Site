# Owner corrections — rules every agent replays before work

- AUTO ADJUST: nothing fixed; never wrap to a second line, never cover; step down (full → short → icon) or hide. (R14)
- Test on all 15 phone sizes, not one; "done" only with the device gate at 0 and screenshots looked at. (R14, the 413 px footer)
- A price line, fit line, label line is ONE line on every device. (R15 2.5, 2.6)
- "All N colours": up to 5 colours after the last swatch; from 6 on the Colour line. Read the owner's words literally ("colour line" = the swatches). (R15 2.2)
- Never take a customer away from a combo to a single product page. (R15 5.1)
- A district or postcode in an address settles the delivery band silently. (R15 Bogura)
- Back must go back exactly one page, to the same scroll position; never a blank page, never jump to Home. (R15 7.1, 12.2)
- Never stop the browser's own behaviours (pull-to-refresh) without putting them back. (R15 6.1)
- Answers and picture labels in simple Bengali. (R15 5.0)
- Nothing the owner asks to remove is deleted — it becomes a switch, off by default. (standing)
- Nothing hardcoded; the owner's personal data never ships to another installation. (standing)
- Fix every bug without asking; for design choices pick one, apply it, keep 2–3 pictures. (R15, 03:34)
- An owner correction can reverse a task mid-way (12:04 → 12:07): build switches and settings first, data changes last, so a reversal costs nothing. (R15)
- On a phone a tap fires mouseenter with no mouseleave — hover logic must check the pointer is a real mouse. (R15, Sawdagor)
- A test that sets the same hash again does not re-draw the page; navigate away first. (R15)
- A Playwright full-page screenshot on a mobile context switches off pointer:coarse for the rest of the session — touch-size CSS must not rely only on pointer:coarse; measure taps before full-page shots. (R15, Gyani)
- Page modules inject CSS after the r12 files — desktop overrides need #app/body weight. (R15, Batch B)
- Splitting a text run into wrappers shifts phone kerning ~1 px: draw split markup on desktop only; use <bdi> for wrappers. (R15)
- Pixel diffs: Playwright animations:'disabled' and identical route lists (history-based rows like Recently viewed change otherwise). (R15)
- Every pause needs a resume test: when a test checks that something stops (hover, focus, touch, popup), it must also check that it starts again at the right moment. A rule written for touch (4 s hold) must not silently apply to the mouse. (R15, owner 21:09 — sliders on desktop)
- If an admin string has its English beside it, keep the pair as {en, bn} or ['English', 'বাংলা'] so the admin-language harvest uses the author's own English; after adding admin strings run tools/extract-admin-bn.py --missing then --merge. (R15, Prohori)
- Demo-only helpers (sample logins, test data, hints for reviewers) must never show to a normal visitor — gate them behind the demo panel (?demo=1) and never ship them. (R15, owner 21:33)
- Pause flags for mouse, touch and keyboard must be SEPARATE (hover / focus / 4 s touch hold), each cleared only by its own event, and every pause needs a tested resume path — a shared flag let a mouse click on an arrow (which focuses it) or the row's own scroll re-arm a pause that nothing ever cleared. (TA-2, T1–T4)
- The production image is built on the VM: the build must not download anything at build time (Google Fonts through next/font/google failed there once) and the Dockerfile deps stage must copy every packages/*/package.json. Fonts are self-hosted in apps/web/src/fonts; CI checks both. (S01, 20 Oct)
