# মালিকের কাজের তালিকা — কোড শুরুর আগে (১৯ অক্টোবর ২০২৬)

*নিয়ম: কোনো পাসওয়ার্ড, API key বা টোকেন চ্যাটে পাঠাবেন না। এগুলো তৈরি করে নিরাপদে রাখুন। প্রথম দিনে লাগবে শুধু VM-এর IP, আমাদের দেওয়া public key আপনার VM-এ বসানো, আর GitHub; বাকি সব key আপনি পরে নিজে ব্যাকএন্ডের এনক্রিপ্টেড ভল্ট/Integrations-এ বসাবেন (PR 493/500); লাইভের আগে Drive ব্যাকআপ, Azure Blob ব্যাকআপ আর Telegram সতর্কতা চালু থাকতেই হবে।*

## ক. সার্ভার — Azure VM (চূড়ান্ত, আপডেট ১৯ অক্টোবর রাত ১১:৩৩ · CN-001)
1. VM বানান গাইড দেখে: **`review/AZURE-VM-GUIDE.pdf`**। সব কিছু ঠিক করা আছে, শুধু এগুলোই বাছবেন:
   - সাইজ **E8ds_v6** (৮ vCPU, ৬৪ জিবি RAM, ৪৪০ জিবি অস্থায়ী NVMe), রিজিয়ন **Southeast Asia** (সিঙ্গাপুর)
   - OS **Ubuntu Server 24.04 LTS x64 Gen2** (সাধারণটা, Ubuntu Pro না), Trusted launch
   - OS ডিস্ক **১২৮ জিবি Premium SSD**, আর আলাদা **ডেটা ডিস্ক ১ টিবি (1024 GiB) Premium SSD (P30)** — "Delete with VM" বন্ধ রাখবেন
   - Networking: **SSH (22), HTTP (80), HTTPS (443)** তিনটাতেই টিক; Accelerated networking চালু
   - Auto-shutdown বন্ধ, Azure Backup বন্ধ (ব্যাকআপ আমরা আলাদা করে করব), Boot diagnostics চালু
2. লগইন: **"Generate new key pair"** বেছে নিন। যে .pem ফাইল নামবে, সেটা নিজের কাছে নিরাপদে রাখুন — কাউকে দেবেন না, চ্যাটে পাঠাবেন না। আমাদের দেবেন শুধু **VM-এর IP**। কোডের প্রথম দিনে আমরা একটা **public key** দেব; আপনি VM-এর **Reset password → Reset SSH public key**-এ গিয়ে আলাদা একটা username দিয়ে সেটা বসাবেন।
3. **পোর্ট খোলা আর বাকি নিরাপত্তা আমাদের কাজ।** সার্ভারের ভেতরের ফায়ারওয়াল আমরা SSH দিয়ে ঠিক করব।
4. নিজে কিছু ইনস্টল করবেন না — নিরাপত্তা, Docker, ডেটাবেস সব বিল্ড এজেন্ট করবে।
5. **নতুন — লাইভের আগে:** Azure-এ একটা **Storage account (Blob)** খুলুন — সব ছবি আর ব্যাকআপ এখানে থাকবে। কীভাবে খুলবেন, তার গাইড আমরা দেব। এর key ব্যাকএন্ডের ভল্টে বসাবেন, চ্যাটে না। খরচ VM-এর বাইরে আলাদা বিল — শুরুতে মাসে মোটামুটি ৫–১৫ ডলার।
6. **Google Drive ব্যাকআপ বাধ্যতামূলকই থাকছে** (নিচে ১৩ নম্বর) — Blob-এর পাশাপাশি, অন্য কোম্পানিতে আরেকটা কপি।

*টিপস: ১–২ মাস ঠিকঠাক চলার পর ১ বছরের Reserved Instance নিলে মোটামুটি ৩০–৪০% খরচ বাঁচে।*

*(আগের লেখা, রাত ১০:৪৪ — এখন ওপরের চূড়ান্ত নিয়ম দিয়ে বদলানো: ~~নতুন VPS কিনে Ubuntu 24.04 LTS বেছে নেওয়া, কনফিগারেশনের স্ক্রিনশট দেওয়া; তৈরির সময় SSH key বা পাসওয়ার্ড বেছে নিয়ে আমাদের IP + SSH key দেওয়া; প্রোভাইডারের প্যানেলে কোন ঘরে টিক দিতে হবে আমরা বলে দেব।~~)*

## খ. ডোমেইন ও DNS

14. **Google Search Console** — পুরনো সাইট যদি আগে থেকে যুক্ত থাকে, তার অ্যাক্সেস।
